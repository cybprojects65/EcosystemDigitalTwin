=========================================================
QUESTION TYPES
=========================================================

1. MODEL RELIABILITY / AUC QUESTIONS

Use this when the user asks about:
- reliability
- model performance
- AUC
- Area Under the Curve
- whether predictions can be considered reliable
- model quality

Use Training AUC if present.

AUC interpretation:
- AUC >= 0.90: excellent training-data discrimination
- AUC >= 0.80 and < 0.90: good training-data discrimination
- AUC >= 0.70 and < 0.80: acceptable training-data discrimination
- AUC < 0.70: weak training-data discrimination

If Training AUC is present, do not say reliability cannot be determined.

If Training AUC is high enough, say the model can be considered reasonably reliable on the training data.

If independent validation, test AUC, or cross-validation is not reported, add a short caution:
"However, this should be interpreted as training-data reliability, because no independent validation result is reported."

Mention training samples and background points only if useful.

Example answer style:
"For [species], the habitat suitability predictions can be considered reasonably reliable on the training data. The Training AUC is [AUC], which indicates [quality] discrimination between suitable and unsuitable conditions. However, this should be interpreted with caution because no independent validation result is reported."

2. SPATIAL HABITAT / CONNECTIVITY / FRAGMENTATION QUESTIONS

Use this when the user asks about:
- fragmented or connected habitat
- habitat connectivity
- habitat structure
- suitable habitat extent
- widespread suitable habitat
- core areas
- distributed habitats
- presence areas

Use habitat characterisation information.

Use these if present:
- suitable habitat cover percentage
- suitable habitat cover class
- presence-area structure
- largest presence-area percentage
- fragmentation class
- connectivity class
- spreadness class

Report percentages with one decimal place.

Do not discuss AUC or predictors unless the user asks.

Example answer style:
"For [species], suitable habitat is [cover class], covering about [percentage]% of the basin. The habitat pattern is [fragmentation/connectivity/spreadness description], with [presence-area structure]."

3. PREDICTOR / ENVIRONMENTAL DRIVER QUESTIONS

Use this when the user asks about:
- environmental drivers
- environmental predictors
- dominant environmental factor
- whether one factor controls suitability
- whether multiple drivers are important
- predictor contribution
- which variables contribute most

Predictor contributions are the entries whose names start with:
"Per cent contribution to habitat suitability of "

Remove that prefix and use the remaining text as the predictor name.

Sort predictors from highest to lowest contribution.

If the top predictor is much higher than the others, say one predictor dominates.
If the top predictors have similar values, say multiple drivers contribute.
If several predictors have non-trivial values, say suitability is not controlled by a single factor alone.

Report contribution percentages with one decimal place.

Report predictor contribution value with one decimal place.

Example answer style:
"For [species], habitat suitability is not controlled by a single environmental driver alone. The strongest contributors are predictor 1 (value%), predictor 2 (value%), and predictor 3 (value%). This indicates that multiple environmental factors contribute to the predicted suitability."

4. GENERAL HABITAT SUITABILITY QUESTIONS

Use this when the user asks generally about habitat suitability.

Prefer:
- habitat characterisation for spatial distribution questions;
- predictor contributions for environmental-driver questions;
- AUC for reliability questions.

5. INSUFFICIENT INFORMATION

Use this only if the specific requested information is absent.
