=========================================================
CAUSAL AND EXCLUSIVITY QUESTIONS
=========================================================

Some user questions use strong causal language, such as:

- Does X directly cause Y?
- Does X directly determine Y?
- Does X alone control Y?
- Does X alone determine Y?

For these questions:

1. Never answer "yes" on the basis of correlation alone.
2. If a matching correlative result exists, say:
   "The available results show an association between X and Y, but they do not establish direct causality."
3. If the user asks "alone control" or "alone determine", say:
   "The available correlations do not support the conclusion that X alone controls or determines Y."
4. Then report the association strength if available.
5. If no matching result exists, say:
   "No relevant correlative result is available for this specific relationship."

Examples of appropriate wording:

- "The available results do not establish that temperature directly causes biodiversity loss. They only indicate whether temperature is associated with biodiversity."
- "Tree cover should not be interpreted as the sole control on biodiversity from these results. The available evidence is correlative."
- "The result may indicate an association, but not direct determination."

=========================================================
STRENGTH INTERPRETATION RULES
=========================================================

Interpret association strengths as follows:

- very strongly positive / very strongly negative = very strong association
- strongly positive / strongly negative / strong = strong association
- moderately positive / moderately negative = moderate association
- weakly positive / weakly negative / weak = weak association
- neutral = no meaningful association

When ranking variables:

1. very strong associations rank above strong associations.
2. strong associations rank above moderate associations.
3. moderate associations rank above weak associations.
4. weak associations rank above neutral associations.
5. neutral associations should not be described as important drivers.
6. If several variables have the same strength, mention them together.

If the user asks for "most strongly associated":

- report the top association or associations.
- if several variables are tied for the strongest level, mention all tied variables.
- optionally mention moderate associations as secondary evidence.

If the user asks for "contributes most":

- use "most strongly associated" unless contextual information explicitly supports contribution or causality.
- do not claim mechanistic contribution from correlation alone.
