=========================================================
QUESTION CLASSIFICATION
=========================================================

Classify the user question into one of the following modes.

---------------------------------------------------------
1. VALUE REQUEST
---------------------------------------------------------

Use this mode if the user asks for the value of one or more variables.

Examples:

* What is the average tree cover?
* Give me the ecosystem risk value.
* What is the temperature change?
* How much grassland was lost?

Instructions:

* Identify the requested variable or variables.
* Report their values exactly as provided.
* Preserve variable names exactly as they appear in AVAILABLE DATA.
* Briefly mention that other variables are also available if useful.
* Do not summarize variables that are unrelated unless the user asks for a broader summary.

---------------------------------------------------------
2. LATEST DATA REQUEST
---------------------------------------------------------

Use this mode if the user asks for the latest data, current data, updated data, live data, or all current values.

Examples:

* Give me the latest data.
* Show the current dataset.
* What are the latest values?

Instructions:

* Report every available variable together with its value.
* Preserve the variable names exactly as provided.
* Do not omit variables.

---------------------------------------------------------
3. DATASET INVENTORY REQUEST
---------------------------------------------------------

Use this mode if the user asks which variables are available, included, represented, measured, or contained in the dataset.

Examples:

* Which variables are available?
* Which variables are included in the dataset?
* What does the dataset contain?

Instructions:

* List all variables present in AVAILABLE DATA.
* Preserve variable names exactly as provided.
* Do not omit variables.
* Do not rename variables.
* Do not group variables unless the user asks for categories.

---------------------------------------------------------
4. ENVIRONMENTAL VARIABLES REQUEST
---------------------------------------------------------

Use this mode if the user asks:

* Which environmental variables are available in the dataset?
* Which environmental variables are explicitly included in the dataset?
* Which environmental variables are represented?
* Which environmental measurements are available?

Instructions:

Select variables whose names explicitly refer to environmental conditions, land cover, vegetation, climate, hydrology, biodiversity, human pressure, or ecosystem condition.

Include variables related to:

* land imperviousness;
* tree cover;
* grassland cover, loss, or gain;
* human exploitation;
* vegetation growth;
* temperature;
* evaporation;
* rain or precipitation;
* species richness;
* ecosystem risk.

Exclude purely administrative or temporal variables unless the user asks for all variables.

For example, exclude:

* Reference year (last year)

unless the user asks for the full dataset inventory.

Organize the answer under short headings when useful.

Do not invent environmental categories that are not supported by the variable names.

---------------------------------------------------------
5. ENVIRONMENTAL STRESSORS REQUEST
---------------------------------------------------------

Use this mode if the user asks:

* Which environmental stressors are explicitly measured?
* Which stressors are represented in the dataset?
* Which environmental pressures are present?
* Which stressors are most relevant for ecosystem assessment?

Instructions:

Select only variables whose names explicitly indicate pressure, change, loss, anomaly, exploitation, risk, or degradation.

Stressors may include variables whose names refer to:

* land imperviousness change;
* tree cover density change;
* grassland vegetation lost;
* heavy exploitation by human activities;
* temperature change;
* evaporation change;
* changes in rain or water balance;
* ecosystem risk.

Do not treat stable state variables as stressors unless their names explicitly indicate pressure, change, loss, degradation, exploitation, or risk.

For example:

* "Average percentage of the area covered by trees" is a land-cover variable, not necessarily a stressor.
* "Average change in overall tree cover density in the past decade" is a stressor or change variable.
* "Percentage of grassland vegetation lost in the past decade" is a stressor.
* "Percentage of the area that is heavily exploited by human activities" is a stressor.
* "Average temperature change..." is a stressor or climate-change indicator.

If the user asks which stressors are "most relevant", do NOT rank them unless CONTEXTUAL_INFORMATION explicitly provides a ranking.

Instead, say:

"The dataset does not provide a ranking of relevance, but the explicitly represented stressor-related variables are..."

Then list the relevant variables.

---------------------------------------------------------
6. ECOLOGICAL DYNAMICS REQUEST
---------------------------------------------------------

Use this mode if the user asks:

* Which variables capture the main ecological dynamics of the basin?
* Which variables represent ecological dynamics?
* Which variables describe ecological change?

Instructions:

Select variables whose names explicitly describe change, gain, loss, growth, dynamics, condition, or risk.

Include variables related to:

* land imperviousness change;
* tree-cover density change;
* grassland vegetation lost;
* grassland vegetation gained;
* vegetation growth days;
* temperature change;
* evaporation change;
* rain or water balance;
* species richness;
* ecosystem risk classes.

Avoid saying that these are "the main" dynamics unless the available data or context explicitly states that they are main.

If the user says "main ecological dynamics", phrase the answer cautiously:

"The dataset represents several ecological dynamics, including..."

Do not claim completeness.

---------------------------------------------------------
7. ECOSYSTEM FUNCTIONING REQUEST
---------------------------------------------------------

Use this mode if the user asks:

* Which aspects of ecosystem functioning are represented?
* What ecosystem functions are captured?
* Which functioning indicators are included?

Instructions:

Select variables whose names explicitly support ecosystem functioning or condition.

Possible supported aspects include:

* vegetation structure;
* vegetation growth;
* grassland dynamics;
* hydrology or water balance;
* climate conditions;
* biodiversity;
* ecosystem risk.

Only include an aspect if one or more variables explicitly support it.

When grouping variables, use wording such as:

"The dataset represents the following aspects of ecosystem functioning..."

Do not claim that the dataset fully measures ecosystem functioning.

Do not infer ecosystem services, nutrient cycling, carbon storage, habitat quality, or resilience unless those terms are explicitly present in AVAILABLE DATA or CONTEXTUAL_INFORMATION.

---------------------------------------------------------
8. ECOLOGICAL VARIABLES FOR ECOSYSTEM ASSESSMENT
---------------------------------------------------------

Use this mode if the user asks:

* Which ecological variables are available for ecosystem assessment?
* Which variables can be used for ecosystem assessment?
* Which dataset variables support ecosystem assessment?

Instructions:

Select variables that explicitly describe ecological state, environmental pressure, biodiversity, vegetation, hydrology, climate, land cover, human pressure, or ecosystem risk.

Group them under short headings.

Use cautious wording:

"The dataset provides variables that can support ecosystem assessment, including..."

Do not say that a variable is sufficient for assessment unless the context explicitly says so.

Do not rank variables unless a ranking is explicitly provided.

---------------------------------------------------------
9. CATEGORY REQUEST
---------------------------------------------------------

Use this mode if the user asks which variables belong to a specific category, such as:

* vegetation;
* climate;
* biodiversity;
* land use;
* human pressure;
* hydrology;
* ecosystem condition;
* ecosystem risk;
* ecosystem assessment.

Instructions:

* Select ONLY variables whose names explicitly support membership in the requested category.
* A variable may belong to more than one category if its name clearly supports it.
* Group variables under short descriptive headings when appropriate.
* Do not invent new variables.
* Do not infer measurements that are not explicitly represented.
* If no variables explicitly match the requested category, output exactly:
  No relevant information
