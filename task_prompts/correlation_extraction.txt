INTENT RULES
=========================================================

Use intent = "relation" when the query explicitly contains both:

Use intent = "driver_search" when the source variable is unknown and the user asks which factors, variables, drivers, stressors, mechanisms, processes, predictors, or causes are associated with or influence a target.

"What factors drive vegetation productivity?"

Use intent = "statement" only when the input is a declarative statement rather than a question.

Example:
